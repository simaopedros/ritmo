Política de Privacidade

App Ritmo · pacote com.ritmo.app · Última atualização: 11 de setembro de 2026

O Ritmo é local-first: hábitos, foco, reviews e progresso ficam no seu dispositivo. No MVP não é necessário criar conta.

1. Quem somos

Esta política descreve como o aplicativo móvel Ritmo (“App”) trata informações. Contato: privacidade@ritmo.app (placeholder — substitua pelo e-mail definitivo antes da publicação nas lojas).

2. Dados que processamos

  • Dados de uso do app (locais): hábitos, conclusões diárias, sessões de foco (Pomodoro), humor/review, streak e preferências. Armazenados no dispositivo (ex.: AsyncStorage).
  • Compras / assinatura: se você assinar o Ritmo Pro, a compra é processada pela Apple (App Store) ou Google (Play Store). Podemos receber, via RevenueCat ou APIs das lojas, o status da assinatura/entitlement (ex.: se você tem Pro), sem receber o número do cartão.
  • Sem conta no MVP: não pedimos e-mail, nome ou login para usar o app na versão inicial.
  • Sem tracking de anúncios: o App não usa IDFA/AAID para publicidade no MVP e não vende seus dados.

3. Finalidade

Usamos os dados locais apenas para fornecer o produto (lembretes de hábitos, timer de foco, review diária, limites Free/Pro). O status de assinatura serve para liberar recursos Pro e restaurar compras.

4. Compartilhamento

  • Apple / Google: processam pagamentos e restauração de compras conforme as políticas deles.
  • RevenueCat (quando configurado): intermediário de assinaturas; recebe identificadores de compra/app necessários para validar o entitlement pro.
  • Não vendemos dados pessoais a terceiros.

5. Retenção e exclusão

Dados locais permanecem no aparelho até você limpar o armazenamento do app ou desinstalá-lo. Para gerenciar assinaturas, use as configurações da App Store ou Google Play. Pedidos adicionais: privacidade@ritmo.app.

6. Crianças

O App não é direcionado a menores de 13 anos. Não coletamos intencionalmente dados de crianças.

7. Segurança

Dados de hábitos ficam no dispositivo. Transações de compra usam os canais seguros das lojas. Nenhum sistema é 100% livre de risco.

8. Alterações

Podemos atualizar esta política. A data no topo indica a versão vigente. Mudanças relevantes podem ser comunicadas no App ou nas páginas das lojas.

9. Contato

Dúvidas sobre privacidade: privacidade@ritmo.app.

URL pública para lojas: https://simaopedros.github.io/ritmo/privacy.html.
